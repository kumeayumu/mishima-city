# 三島市版：2026年度の公式資料

- 対象は開催年月が2026年4月〜2027年3月の議案一覧と、開催日が同期間の公開会議録。
- 議案の件名に書かれた予算・決算年度での絞り込みではない。2026年度の会議に提出された2025年度決算も対象。
- 2026年2〜3月の定例会・委員会は除外。2027年4月以降も除外。
- 未開催でも2026年度の会議に向けて公式公開済みの提出議案は含む。未掲載の議決結果を推測しない。

## 公式出典

- 議案一覧：https://www.city.mishima.shizuoka.jp/site/gikai/list216-519.html
- 会議録：https://ssp.kaigiroku.net/tenant/mishima/SpTop.html
- 会議録は公開検索画面と同じAPIを使用し、自治体ID406の公開情報のみ取得。

## 再取得

Node.js 24とpnpmを使用する。

~~~sh
pnpm install --frozen-lockfile
pnpm sources:mishima
# キャッシュを更新する場合
pnpm --filter @mirai-gikai/seed sources:mishima --refresh
~~~

取得原文・API応答は `artifacts/mishima/2026/` に保存（Git管理外）。
画面用データは `web/src/features/official-records/server/data/2026/` に保存（Git管理）。
再実行はキャッシュから再開するため、公開資料を更新するときは必ず `--refresh` を付ける。
HTTP失敗・解析不能・開催日不明・空の会議録はエラーとして終了する。
DBには書き込まない。AI生成要約も作成しない。

## 初回取得

2026年11月14日取得：議案62件（5月臨時会、6月・9月・11月定例会）、会議録7日分・922件の記録（5月臨時会と6月定例会）。会議録は未公開の期間を補完しない。

公式一覧の議案番号と件名内の番号が異なる場合は、番号・件名の両方を原文のまま保持して注意を表示する。個別PDFによる確認前に自動修正しない。

## 表示と未設定項目

公開トップと `/minutes/[id]` は公式スナップショットを表示するため、DB接続は不要。
既存の管理画面や議案編集などのDB機能には別途Supabaseが必要。ローカルDockerは現環境では未検出のため、ローカルSupabaseの起動・取り込み検証は未実施。
名称、議会URL、ロゴ、アイコン参照、ソースコードリンクを三島市版へ変更。
福岡市の選挙・財政・委員会・記者会見・事務事業の未移行ページは404とし、トップからの導線を除去。
福岡市の写真をトップから除き、福岡市版OGP画像の参照を除去。
運営者名・連絡先・管轄は未設定。公開運営開始前に決定して設定する。

~~~
