## NEXT_PUBLIC_WEB_URL

metadataBaseとsitemapの絶対URLに使用する。DB接続や認証には使用しない。
優先順位: 明示したNEXT_PUBLIC_WEB_URL → VercelのVERCEL_URLにhttps://を付与 → ローカルhttp://localhost:3002。
Vercel環境で両方がない場合はビルドを失敗させ、localhostを公開設定に混入させない。
初回はNEXT_PUBLIC_WEB_URLを未設定にし、Vercelの自動システム環境変数を有効にしてデプロイごとのURLを使う。初回URLを事前に推測して登録する必要はない。
固定の独自URLを使う場合のみ完全なhttps://のoriginを指定する。公開値であり秘密情報を入れない。変更後は再ビルドが必要。
Preview用にProduction URLを流用しない。保存済み autoExposeSystemEnvs=true をAPIで確認済み。実行前にも再確認する。
